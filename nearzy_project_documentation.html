1 Executive Summary & Product Vision

Nearzy is a modern, high-performance hyperlocal marketplace built specifically for Tamil Nadu. It seamlessly connects residents with verified local service professionals (electricians, plumbers, AC technicians, beauticians, carpenters) within a precise 30-kilometer geographical radius. Featuring real-time Leaflet maps, an intelligent bilingual AI assistant, and instant role-based dashboards, Nearzy digitizes neighborhood trades with zero friction.

5 Database Architecture & Automated Triggers

The relational database runs on Supabase PostgreSQL. It strictly enforces foreign keys, cascades, and security policies. User authentication directly activates database-level triggers to guarantee zero orphaned records.

Table Name Primary Columns & Relations Purpose & RLS Policies
auth.users id (UUID PK), email, encrypted_password, raw_user_meta_data Supabase internal authentication store. Manages encrypted user credentials, email confirmation tokens, and sessions.
public.profiles id (UUID FK → auth.users), display_name, email, phone, preferred_language Public profile entity. Populated instantly via handle_new_user() trigger. Viewable by public, updatable only by the owner.
public.user_roles id (PK), user_id (FK → profiles), role ('customer' | 'business_owner' | 'admin') Role-based access control (RBAC). Determines permissions for managing listings, claiming shops, or moderating content.
public.businesses id (PK), category_id, name, slug, address, locality, city, latitude, longitude, phone, is_verified, created_by Stores 760+ localized service businesses across Tamil Nadu. Indexed with geographic coordinates for fast spatial querying.
public.services & bookings id, business_id, name, price, duration_minutes | customer_id, booking_date, status Transactional booking subsystem. Allows customers to book appointments and track status (pending, confirmed, completed).

Automated Signup Database Trigger: public.handle_new_user()

When a user signs up through supabase.auth.signUp(), the trigger on_auth_user_created immediately executes public.handle_new_user() on PostgreSQL. It extracts the display name, email, and preferred language from metadata and inserts atomic records into public.profiles and public.user_roles. This ensures frontend code never has to perform manual profile bootstrapping.

8 Key Questions & Answers (Everything You Need to Know)

Q1 What is Nearzy and what core problem does it solve?
Nearzy is an on-demand hyperlocal service discovery platform for Tamil Nadu. It solves the fragmentation of finding verified neighborhood electricians, plumbers, carpenters, and beauty technicians by providing real-time 30 km radius matching, bilingual navigation, and direct booking.
Q2 Which tools and agent were used to create this website?
The website was developed using Google DeepMind Antigravity (Advanced Agentic AI Coding Assistant) paired with the human engineer. Development tools included VS Code, Node.js v20+, Vite, Git CLI, and Supabase CLI for schema migrations.
Q3 Where is the source code hosted and how is version control managed?
The complete source code is hosted on GitHub at https://github.com/JoTech17/Nearzy.git. Version control uses dual synchronized branches (master and main) with atomic commits and semantic feature tags for instant redeployment.
Q4 Where is the website deployed and how does routing work?
The frontend is deployed as a high-speed Single Page Application (SPA) on modern cloud hosting (Vercel / Netlify Edge). Routing is powered by React Router v7 with rewrite rules configured in vercel.json to ensure all deep links (e.g., /register-business, /privacy, /admin) load smoothly without 404 errors.
Q5 What database is used and how is user information stored?
Nearzy uses Supabase PostgreSQL. User authentication is managed in auth.users, which automatically synchronizes with public.profiles via the PostgreSQL trigger handle_new_user(). Role separation (Customer, Business Owner, Admin) is maintained in public.user_roles with Row Level Security.
Q6 How does the AI Assistant provide accurate answers and 30 km recommendations?
The assistant is powered by Google Gemini Flash via REST API. When a query is received, it resolves the location coordinates against a master dataset of 38 Tamil Nadu districts and applies the Haversine formula to return exclusively verified providers within 30 km.
Q7 How can an administrator verify registered profiles in the database?
Administrators have three convenient methods: (1) Running npm run check:profiles in the terminal to inspect live database records, (2) Visiting the Registered Profiles tab on the Nearzy Admin Console (/admin), or (3) Checking the profiles table directly in the Supabase Dashboard.
Q8 How does the bilingual English and Tamil feature work?
The bilingual engine is powered by React's Context API (LanguageContext.jsx). All navigation, category titles, service details, and legal pages are stored as clean bilingual dictionaries with instant one-click switching and zero page reload delay.
Q9 How was the UI made modern, smooth, and interactive?
We integrated Tailwind CSS for a sleek red-black-white visual hierarchy, coupled with Framer Motion for spring physics modals, smooth page route transmissions, interactive Leaflet map markers, and animated drawer menus.
Q10 What are the next planned enhancements for Nearzy?
Planned milestones include Razorpay UPI payment gateway settlement, SMS / WhatsApp OTP notifications via Twilio / Gupshup, and a progressive web app (PWA) offline mobile service provider portal.
